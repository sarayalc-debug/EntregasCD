# Ejercicio 1 - Diseño con Tarjetas CRC

| Clase: Libro | |
|---|---|

| Conocer título, autor e ISBN | - |
| Conocer número de ejemplares disponibles | - |
| Prestar un ejemplar (si hay disponibles) | Préstamo |

| Clase: Socio | |

| Clase: Préstamo | |
|---|---|

## 2. Préstamo de ejemplar
Antes de prestar Libro verifica si hay ejemplares disponibles.
Si hay, resta uno y confirma que el Préstamo se ha realizado al Socio.
Si no hay, se rechaza la petición y el número de ejemplares no cambia.

## 3. Descripción del flujo
Se da de alta un libro con 3 ejemplares. Libro registra 3 unidades disponibles del libro.
Se dan de alta dos socios. Socio da de alta 2 socios nuevos.
El primer socio toma prestado el libro (¿tiene éxito?). Socio 1 quiere tomar prestado un Libro. Libro verifica que tiene 3 unidades disponibles, la acción tiene éxito. Se resta una unidad de Libro disponible, quedan 2 unidades disponibles. Préstamo registra el Socio que tiene el Libro, la fecha de préstamo y la fecha máxima de devolución.
El segundo socio intenta tomar el mismo libro (¿tiene éxito?). Socio 2 quiere tomar prestado un Libro. Libro verifica que tiene 2 unidades disponibles, la acción tiene éxito. Se resta una unidad de Libro disponible, queda 1 unidad disponible. Préstamo registra el Socio que tiene el Libro, la fecha de préstamo y la fecha máxima de devolución.
El primer socio devuelve el libro. Socio 1 devuelve el Libro. Préstamo registra la devolución del Libro. Libro añade 1 unidad del Libro disponible, hay 2 unidades disponibles.
El segundo socio vuelve a intentar tomar el libro (¿tiene éxito?). Socio 2 quiere tomar prestado el mismo Libro. Libro verifica que tiene 2 unidades disponibles, la acción tiene éxito. Se resta una unidad de Libro disponible, queda 1 unidad disponible. Préstamo registra el Socio que tiene el Libro, la fecha de préstamo y la fecha máxima de devolución.

### Resumen del flujo

| Paso | Acción | Clase que actúa | Colaboradores | ¿Éxito? | Ejemplares disponibles tras acción |
|---|---|---|---|---|---|
| 1 | Alta del libro (3 ejemplares) | Libro | - | Sí | 3 |
| 2 | Alta de dos socios | Socio | - | Sí | 3 |
| 3 | Socio 1 toma el libro | Socio | Libro, Préstamo | Sí | 2 |
| 4 | Socio 2 toma el libro | Socio | Libro, Préstamo | Sí | 1 |
| 5 | Socio 1 devuelve el libro | Socio | Libro, Préstamo | Sí | 2 |
| 6 | Socio 2 vuelve a tomar el libro | Socio | Libro, Préstamo | Sí | 1 |
